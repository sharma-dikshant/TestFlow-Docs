# API Design Specification

## Base URL

```
/api/v1
```

---

## Authentication Module

### Endpoints

| Method | Endpoint                        | Description          |
| ------ | ------------------------------- | -------------------- |
| POST   | /auth/login                     | Login user           |
| POST   | /auth/register                  | Register user        |
| POST   | /auth/refresh                   | Refresh token        |
| POST   | /auth/logout                    | Logout user          |
| POST   | /auth/otp                       | Send OTP             |
| POST   | /auth/otp/verify                | Verify OTP           |
| GET    | /auth/oauth/{provider}          | Redirect to provider |
| GET    | /auth/oauth/{provider}/callback | Handle login/signup  |
| POST   | /auth/password/forgot           | Request reset        |
| GET    | /auth/password/reset/verify     | Validate token       |
| POST   | /auth/password/reset            | Set new password     |

---

## Users Module

### Base CRUD

| Method | Endpoint          | Description              |
| ------ | ----------------- | ------------------------ |
| POST   | /users            | Create user              |
| GET    | /users            | Get users (with filters) |
| GET    | /users/{username} | Get user by username     |
| PATCH  | /users/{username} | Update user              |
| DELETE | /users/{username} | Soft delete user         |

### Filters

```
GET /users?email=abc
GET /users?username=john
GET /users?status=active
GET /users?verified=true
GET /users?role=admin
GET /users?created_at=gte:2026-05-01
```

### Special Actions

| Method | Endpoint                     | Description     |
| ------ | ---------------------------- | --------------- |
| PATCH  | /users/{username}/activate   | Activate user   |
| PATCH  | /users/{username}/deactivate | Deactivate user |
| PATCH  | /users/{username}/restore    | Restore user    |

## Query Standard

### Filtering

```
?field=value
?field=gt:10
?field=lt:100
?field=gte:2026-01-01
?field=lte:2026-12-31
```

### Search

```
?search=keyword
```

### Sorting

```
?sort=created_at&order=desc
```

### Pagination

```
?page=1&limit=10
```

{

    "limit": 10,
